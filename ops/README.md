# ops/

The build-process harness — not product documentation, and not needed to run
the app.

- **`Supervisor.md`** — supervisory-architect prompt: owns the ticket backlog
  and the `TASK.md` lifecycle.
- **`Nightly_Review.md`** — the review procedure the nightly run applies to the
  previous session's diff.
- **`TASK.md`** — the in-flight ticket, generated by Supervisor. Transient: it
  exists only while a ticket is being worked, and is archived to `task-archive/`
  when the ticket ships. Absent between cycles.
- **`tickets/`** — ticket drafts (`GENXUI-N_ticket_draft.md`). Historical once
  the ticket ships; the authoritative trail is the `GENXUI-N:` commit messages.
- **`task-archive/`** — completed `TASK.md` files, one per finished ticket.

These were moved here from `docs/` in the repo reorg. The historical ticket
drafts reference `docs/proposal_*.md`, `docs/design/…`, and
`GENXUI-Refresh_Master.md` — a set of design notes and a roadmap doc that were
removed once the refresh shipped. Recover any of them from git history if
needed (`git log --all --diff-filter=D -- 'docs/**'`).
