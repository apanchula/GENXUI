# docs/

Documentation that stays useful after the code is written.

- **`ROADMAP.md`** — the v2 refresh vision and phase breakdown.
- **`design/`** — design records for individual features (the "why" behind a
  module). Source files link here in their module docstrings. These are kept
  even after the feature ships; they answer maintenance questions.

Build-process material — the nightly ticket pipeline, ticket drafts, and the
transient `TASK.md` — lives in [`../ops/`](../ops/), not here.

For **using** the app, see the top-level [`../README.md`](../README.md).
